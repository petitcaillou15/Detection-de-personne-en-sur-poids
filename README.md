# Détection de personnes en surpoids

## But

Le but de ce projet est de se familiariser avec les principes fondamentaux du machine learning et essayer les différentes méthodes 
(SVM, réseaux de neurones, régressions linéaires, ...) afin de savoir laquelle est la plus adaptée à notre problème et pourquoi. 
De plus, rendre les données utilisable et lisible par l'algorithme est primordial au même titre que l'analyse (vérification des dépendances, équilibre, ...) de celle-ci.

## Conclusion 

La plus grande difficulté a été de transformer les données tout en choisissant les bonnes méthodes et en faisant attention à la multicolinéarité.
